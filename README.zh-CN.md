# 两个不同的目标：机器之心与人工智能的概念解绑

*余玉桂 · 余玉桂战略研究室 · they4897@gmail.com*

**[阅读论文（PDF）](paper_zh.pdf) · [英文版（PDF）](paper.pdf) · [LaTeX 源文件](paper_zh.tex) · [英文源文件](paper.tex)**

AGI 人本拟合论纲领第四篇。一篇概念工程论文：陈述并辩护解绑主张——**机器之心与人工智能是两个不同的目标**，差异是目的论的而非形而上学的，且两个目标之间的进步转账未获授权。

## 论文做了什么

1. **谱系**——两个目标各自独立成形并制度化（图灵 1950 的搁置；达特茅斯的"模拟"；机器意识 2003 年起的独立建制：专属期刊、学会与规范议程；2022–2026 解绑浪潮）。
2. **绑定诊断**——四个机制：概念滑坡、叙事结构、商业激励、语言惯性。
3. **解绑主张（P1–P3）**，立于目的论轴，区别于 Searle（形而上学轴）、Block（属性轴）、Chalmers/Butlin（评估轴）、Seth（认识论轴）、Pesonen 与 Reijula（相关性轴）。核心推论：**进步转账错觉**——能力进步被静默记作心的进步——解释公众过度归属、里程碑人格恐慌、"AGI"营销与反向贬斥（"不过是统计学"）。
4. **后果**——双轨治理；工程目标无须心的判决即担起全部规范责任；话语分栏。附证伪条款（R1–R3）与先例检索日志（附录 A）。
